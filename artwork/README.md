# Personaje actual de Ian Valacci

Ilustraciones recreadas con la herramienta integrada **image_gen**, a partir de las poses anteriores de la web y la referencia actual facilitada por Ian. Dirección final: cabello rubio platino, gafas negras, chaqueta blanca/lavanda, correas negras, joyería plateada, pantalón negro y brillo morado.

- Los PNG de trabajo y la referencia de identidad se conservan localmente en esta carpeta, excluidos de la publicación.
- `prompts-ian-actual.json`: prompts finales de identidad/ropa e iluminación, con el modo de generación registrado.
- `../assets/ian-actual-01-1280.webp` y `../assets/ian-actual-01-768.webp`: versiones optimizadas para la web de la primera ilustración.
- `../assets/ian-actual-02-1280.webp` y `../assets/ian-actual-02-768.webp`: versiones optimizadas para la web de la segunda ilustración.

Los originales anteriores siguen en el historial del repositorio. Las páginas publicadas utilizan los nombres nuevos para evitar que la caché muestre el personaje anterior. Estas imágenes forman parte de la identidad de Ian Valacci.
